# Fitness Tracker Web Application

## Description
The Fitness Tracker is a web-based application that allows users to log workouts, track exercise duration, calculate calories burned, and visualize progress through charts.

The application also provides fitness suggestions based on the user's selected fitness goal.

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- Chart.js

## Features
- Log daily workouts
- Track exercise duration
- Automatic calorie calculation
- Workout history table
- Bar chart for daily calorie progress
- Pie chart showing exercise distribution
- Goal-based fitness suggestions

## How to Use
1. Open the `index.html` file in a web browser.
2. Enter workout details:
   - Date
   - Exercise
   - Duration
3. Click **Add Workout**
4. View workout history and charts.
5. Select a fitness goal to get suggestions.

## Future Improvements
